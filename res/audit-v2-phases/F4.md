## Behavior decisions

- **Projection is a battle-long mark, not a struct field.** The human seat's
  upcoming hand is pre-rolled once into a `NEXT_HAND` `eff_noop` mark on the seat
  effect list (subject = side in `args[0]`, tag in `args[1]`, count in `args[2]`,
  ready flag in `args[3]`, projected `Card*` in `args[5..14]`). This follows the
  established `effect_find_mark` idiom (Reforge, move/flip marks) and the memory
  rule that per-item/shared state belongs in a mark or effect context, never in
  `BattleState`/`PlayerState`. Projected `Card*` are borrowed `CARD_REGISTRY`
  pointers, so they sit in `args[]` leak-free.
- **turn_start pipeline.** For the human seat, `turn_start` now (1) ensures this
  turn's projection, (2) realizes it verbatim into the hand and fires
  `ON_CARDS_DRAWN`, then (3) pre-rolls the next turn's projection so preview
  effects played this turn can edit it. Realization copies the finalized
  projection, so **previewed hand == realized hand** by construction.
- **`QUERY_NEXT_HAND` (new trigger).** Fired once per projection build with the
  mutable `Card**`. Lucky Strike moved from `ON_CARDS_DRAWN` to this trigger, so
  its highest-tier promotion of slot 0 is baked into the projection and survives
  to realization; bonus draws (which still fire `ON_CARDS_DRAWN`) no longer
  wrongly re-promote. Its old per-turn guard was dropped: one fire per projection
  makes it redundant, and keeping it broke the two-projections-in-one-turn_start
  case. Draw count still folds through `QUERY_CARD_DRAW_COUNT` inside the
  projection build (Rich/Sparse), and the eligible pool is built through
  `battle_draw_pool`, so `QUERY_CARD_CAN_DRAW` (Kingdom Purity) still filters the
  projection.
- **Counsel through the existing target machinery.** Replaced the
  `QUERY_CARD_CAN_DRAW` veto approximation with `QUERY_CARD_TARGETS`
  (`eff_counsel_peek`, advertises each projected slot as `TARGET_CARD`) plus
  `ON_CARD_TARGET_SELECTED` (`eff_counsel_discard`, drops the chosen slot and
  refills via `battle_next_hand_discard`). No veto approximation remains.
- **Generic active items (one new trigger, `ON_ITEM_ACTIVATE`).** The planned
  `QUERY_ITEM_ACTIVATABLE` trigger was **dropped as an over-engineering** — the
  usable check reads each `ON_ITEM_ACTIVATE` effect's own context directly
  (`args[0]` once-per-battle flag, `args[1]` once-per-turn stamp), so no separate
  probe effect and no probe/body pairing are needed. `battle_item_list` /
  `battle_item_usable` / `battle_item_activate` are agnostic: they name no relic.
  Deep Hand draws two immediately (`battle_draw`, the bonus path) and sets the
  battle flag; Librarian's Notes skips the top projected card
  (`battle_next_hand_discard(…, 0)`) and stamps the turn. "Play or sell that
  turn" for Deep Hand is enforced by the existing end-of-turn autosell.
- **No battle serialization.** `engine_save` refuses mid-battle
  (`engine.c:111`), so the projection is transient and needs no save/load; the
  F4 gate does not require it.
